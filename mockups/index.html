Spine Strip — Signature

4dp di kiri card meng-encode 2 status: warna = readingStatus (merah Sedang, abu Belum, stripe Dropped), dot 6dp = publikasi (● Tamat / ○ Ongoing). Di Reader memanjang jadi Progress Ledger.

Alur Utama

Baca & bookmark: Terbaru/Search → Detail → Chapter → Reader → bookmark → auto-tag Tamat muncul di Library.
Lanjut baca: Library filter Sedang Dibaca → tap card → langsung Reader di P.04 (<3 tap).

Debounce 450ms, cache 10m, OkHttp 10MB, token bucket 30/menit, queue + retry backoff. Jangan batch-fetch thumbnail — Coil lazy load.
